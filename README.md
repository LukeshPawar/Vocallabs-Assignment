## About Subspace.money

Subspace.money is a bootstrapped, profitable Indian fintech product that lets users manage subscriptions, split group bills, pay recurring expenses, and access India's first subscription marketplace. Key stats as of FY25:

- **₹36.5 Cr ARR** with zero external funding
- **90%+** operations powered by autonomous AI agents
- Unique moats: Negotiate API (automated price negotiation), group sharing network effects, and a proprietary subscription marketplace for local Indian providers

## Teardown Methodology

Each of the 5 feedback points is structured as:

- **(a) Observed** — What I actually saw in the app / website / flow
- **(b) Problem** — The real user or business pain it causes
- **(c) Ship instead** — A specific, actionable solution

Frameworks applied include **SWOT**, **Porter's Five Forces**, and **7Ps** where relevant.
